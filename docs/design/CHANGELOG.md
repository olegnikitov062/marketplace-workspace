# Изменения локального дизайна

## 30.09.2026 — версия 2

По замечанию Олега и выбору «Светлая таблица в духе Airtable: тонкие линии, минимум цвета» создана новая рабочая поверхность. Добавлены комбинируемые сортировки, группы до трёх уровней, фильтры И/ИЛИ, параметры колонок, статическое и условное оформление, личные именованные виды, ручные поля и CSV. Расширенное описание системы приведено к выбранному направлению; текущие статусы основного плана не менялись.

Проверены браузерные сценарии, расчётные функции и CSV. Исправлены при проверке: доступные итоги по типам полей, поиск в пределах доступных полей профиля, сохранение черновиков, пересчёт ручной себестоимости, единицы счётчика, мобильное закрепление колонок и возврат фокуса после перерисовки. Подробный состав проверок и ограничения — в [README.md](README.md).

Версия 1 перед изменениями сохранена в .change-backups/design-v1-20260930-162259/. Контрольные суммы выдаваемых файлов — [checksums.sha256](checksums.sha256).
